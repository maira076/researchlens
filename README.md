
# ResearchLens

ResearchLens is an AI-assisted research paper interpretation tool.

Its core innovation is **knowledge-level adaptive scientific interpretation**.

Users can upload a research paper and select:

- Beginner
- Student
- Researcher

ResearchLens then provides a structured interpretation covering:

- Research problem
- Objective
- Methodology
- Dataset / sample
- Tools and models
- Evaluation
- Key findings
- Limitations
- Research gap
- Future work
- Practical significance
- Key terminology
- Critical reading notes

## Technology Stack

- Python
- Streamlit
- PyMuPDF
- Google Gemini

## MVP Architecture

app.py → paper_utils.py

## Important

ResearchLens is an interpretation aid and should not replace reading or citing the original research paper.
